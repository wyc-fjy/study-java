# 变量
### 变量定义格式
数据类型 变量名 = 数据值;

### 变量的使用方式
1. 输出打印\
`int a = 10;`
`System.out.println(a);`
2. 参与计算\
`System.out.println(a+b);`
3. 修改记录的值
```
int c = 10;
c = 20;
System.out.println(c);
```

### 注意事项
1. 在一条语句中，可以定义多个变量
2. 变量使用之前必须要赋值

## 变量的练习-计算公交车人数
1——上1\
2——上2下1\
3——上2下1\
4——上0下1\
5——上1下0\
求终点站乘客人数
```
static void main(String[] args) {
int count = 0;
count = count + 1;
count = count + 2 - 1;
count = count + 2 - 1;
count = count - 1;
count = count + 1;
System.out.println(count);
}
```
