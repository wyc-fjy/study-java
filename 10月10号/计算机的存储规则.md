# 计算机的存储规则
计算机中的数字
1. text文本——数字、字母、汉字
2. image图片
3. sound声音

**在计算机中，任意数据都是以二进制的形式来存储的**

| 进制 | 前缀 |
| :--- | :---: |
| 二进制 | 0b |
| 十进制 | （无） |
| 八进制 | 0 |
| 十六进制 | 0x |

```
static void main(String[] args) {
     System.out.println(17);
     System.out.println(017);
     System.out.println(0x123);
    }
```

## 任意进制转十进制
公式：系数*基数的权次幂 相加

- 系数：每一位上的数
- 基数：当前进制数
- 权：从右往左，依次为0，1，2...

## 十进制转其他进制 
除基取余法（几进制，基数就是几）
