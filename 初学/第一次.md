# GitHub 笔记核心步骤

## 首次配置

```bash
cd ~/Desktop/python_for_Wang/study-java
git init
git remote add origin https://github.com/wyc-fjy/study-java.git
git remote -v
```

推送时如果要求登录：

- Username：`wyc-fjy`
- Password：GitHub Personal Access Token

## 每次写笔记

### 1. 在 PyCharm 写笔记

```text
notes/笔记名.md
```

### 2. 在终端执行

```bash
git pull
git add .
git commit -m "更新笔记"
git push
```

### 3. 到 GitHub 查看

```text
https://github.com/wyc-fjy/study-java
```
